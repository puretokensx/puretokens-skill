# Switch × Skills 实机验收方案与费用边界

本方案不授权任何实机或计费请求。1.0.0 的发布验收例外仅允许发布，
不授权新增测试，不把待验收项改为通过。发布证据见
[1.0.0](acceptance/1.0.0-release.md)，当前结果见
[宿主验收记录](host-acceptance.json)。

每次执行前固定客户端、系统、架构、Skills 执行器 SHA、Switch／客户端版本、
会话模式和报价有效时间。不能用一次 Web 生成覆盖客户端矩阵。

## 第一阶段：不产生专用模型计费

1. 使用测试账户和两类明确分组（聊天＋含目标模型；聊天＋不含目标模型）。
   由用户在 Switch 选择并应用，只记录脱敏结果和版本，不导出或索取 Key。
   配置应用、Key 刷新若需自动操作，先纳入授权。
2. 选择一个明确已配置且可运行工具的客户端；VS Code 多模型连接、TRAE
   和 Claude 映射模式各有独立边界，不能由另一个客户端代验。
   安装已验证稳定版后新开对话，确认加载路径、版本和本地执行能力。
   启动 Agent 可能消耗聊天 token，须纳入总预算，不能称整个阶段免费。
3. 由该宿主执行用户明确要求的模型发现，记录目标精确 ID 是否可见，
   核对所选分组的完整模型并集。此步只验目录投影，不验专用 API。
   不运行所有客户端探测，不借用其他客户端的 Key。
4. 改变多分组名单并重新应用，确认增加／移除均生效；不同 Key、被拒绝 Key、
   命名／便携／远程 profile、会话覆盖单列。优先用合成夹具测试拒绝路径；
   不修改生产 Key 制造故障。真实拒绝 POST 也需授权，服务端错误放行可能计费。

## 第二阶段：首个宿主的有限专用请求

先完成加载、连接和目录核对，再确定下表每行的精确模型、已安装 profile
允许的参数／输入传输、权威报价及预算。下表是测试模板，不是提交指令。
每行最多一次 POST，不自动批量启动，不因超时或交付失败重提；已有 ID
仅继续原任务。需要再次生成时另行获得授权。

| 用例 | 选择与输入边界 | 最多提交 | 通过条件 |
| --- | --- | --- | --- |
| 图片生成 | 当前默认 gpt-image-2.6；选已声明的最小输出，1张非私人图案 | 1 | 原任务完成，客户端实际打开图片或交付附件 |
| 图片编辑 | 同模型及声明的本地编辑 operation；使用上一行原图字节 | 1 | 原字节提交，结果实际可打开 |
| 视频生成／图生视频 | 当前默认 MiniMax-H3；按其精确 profile 选择模式和参数 | 1 | 原任务视频实际播放／交付；参考输入角色保持不变 |
| 配音 | 选已审音频 profile，不超过30字及有权限的音色 | 1 | 对应专用接口、有效音频、客户端实际播放／交付 |
| 转写 | 选已审转写 profile，使用上一行音频的当前附件字节 | 1 | 原字节提交，最终转写文本真实展示 |
| 声音场景 | 选已审声音生成 profile，一句短场景 | 1 | 有效音频和真实播放／交付 |
| 音乐 | 明确选定一种已审协议：同步、StepFun 异步或 Gemini/Lyria 异步 | 1 | 使用对应 API／生命周期，原生音频实际播放／交付 |
| Jev | 选审核精确 ID；短文本和有界 Choice/Score/Noul | 1 | 原始选项、数值、概率／legend 按类型真实展示 |
| 向量 | qwen3.7-text-embedding；两条非私人短文本 | 1 | 有序、维度一致的 JSONL 保存并真实交付 |
| 重排 | qwen3.7-text-rerank；一个 query 和三条非私人候选 | 1 | JSON 排名与原输入索引一致，真实展示／交付 |

模板上限为每个宿主十次专用提交，不是预先批准的额度。只执行已获授权的行；
缺权限、报价或输入条件时跳过，不换模型。MiniMax-H3 当前参考输入要求公开
HTTPS URL，不能把上一行本地图片冒充 URL 或额外上传。要测本地首帧，应在
授权前另选明确支持本地附件的精确模型并重新报价。
GIF、SVG、尾帧、同步／异步音频等不同结果协议需要独立用例和单独预算，
不能把一种格式或一个音乐模型的成功推广为全部输出支持。

## 成本核对

已从执行方案移除 2026-09-29 的旧价格和退役模型示例；历史快照仍在
[当时的目录证据](acceptance/switch-skill-public-catalog-20260929.json)。
旧目录、安装 profile 或模型可见性都不是当前报价或账户权限的证明。

执行前取得所选分组的权威报价：精确 ID、币种、计费单位／表达式、参数、
分组倍率、适用范围和有效时间。计算每个用例、实际计划提交总量的成本上界，
单列聊天 token 预算，向用户说明后获得明确授权。
报价未知的行暂停，不能称免费；只有预算总数而不能估计单次上界时也不执行。
本仓没有权威自动报价或计费前预留接口，不能虚构相关保证。

## 验收记录

按 [验收指南](host-acceptance-guide.md) 记录实际客户端用例，覆盖分组内／外、
多分组刷新、多 Key、会话覆盖和原生输出。网络失败、未知提交或下载失败
保留原任务与未知状态，不因“不显示附件”重新生成。
金额以服务端账本为准，目录价格和客户端推算不能冒充实际扣费。
仅保存脱敏模型 ID、状态码、次数、允许的耗时指标、可见性、费用及交付结论；
不保存 Key、请求正文、用户媒体或原始响应。五项链路中有任一缺口，
该客户端／能力不标“实机通过”。
