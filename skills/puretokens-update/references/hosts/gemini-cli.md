# gemini-cli

Bound host: `--host gemini-cli`.

Use ~/.agents/skills when an official Skill already exists there, because Gemini discovers it before ~/.gemini/skills; report lower-priority managed duplicates without deleting them.

Install into ~/.gemini/skills. The native executor has credential-format fixture coverage; actual host API and attachment delivery acceptance is pending.

Read [sanitized diagnostics](../host-errors.md) only after a local failure.
