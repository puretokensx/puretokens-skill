# Pure Tokens Skill 使用须知

## Pure Tokens 是什么

Pure Tokens 是一个提供多种模型能力的 AI 服务平台。你可以在网页中聊天和创作，也可以把连接配置到受支持的 AI 客户端；安装官方 Skills 后，可以在对话中提出图片、视频、音频创作、Jev 文本评估、文本向量或重排等任务。具体能否完成，取决于安装版本、客户端适配、所选模型权限和结果交付能力。

按用户所问回答：仅问“是什么”，用上面两三句话即可；问“能做什么”，补充相关能力和一两个示例；问“怎么开始”，再解释下面的入口。示例仅展示，不执行，不把介绍变成安装、连接检查或付费体验。

| 用户想做什么 | 从哪里开始 |
| --- | --- |
| 在网页聊天或创作 | 从 [Pure Tokens 官网](https://www.puretokensx.com) 进入相应网页工具，无需先安装客户端 Skills。 |
| 给受支持的 AI 客户端配置连接 | Pure Tokens Switch 用于选择模型分组并应用客户端连接配置；用户在 Switch 中操作，Skill 不代改连接。 |
| 在客户端对话中使用专用能力 | 客户端连接配置好后，单独安装官方 Skills，并按该客户端的加载步骤使用。已有可用且受适配器支持的连接无需为了 Skills 再安装 Switch 或重配。 |

只需相应专用模型的 API 权限，不要求它进入聊天模型列表。模型目录可见、安装完成、能聊天或 init 成功，均不能单独证明某项专用任务和附件交付可用；不承诺所有客户端、分组或模型都支持。

帮助分支只读本地指南，不要求已配置连接，不追问宿主，不读取凭据或调用执行器；不会新增 API 请求或计费任务，也不自动安装、开网页或操作 Switch。介绍中的能力类别不代表实时模型名单、价格、可用性或账户授权。

- 明确问“现在有哪些模型／这个模型支持什么”：使用 puretokens-models 对应查询；最新分组按该 Skill 的公开分组指引，不猜名称。
- 问价格：引导查看官方[模型广场](https://docs.puretokensx.com/models)的当前信息；本地指南不提供精确报价，不把余额查询当报价，也不承诺免费。
- 问“我的连接还能用吗”：使用一次有界 init；明确核验固定 API 公开身份才用 puretokens-connection。介绍加连接检查的混合请求只增加这一个明确要求的检查，不串行探测。

产品定位核对来源：[官网公开介绍](https://www.puretokensx.com)，2026-10-13。此处只保留产品分工；动态信息通过上述入口取得，不为普通介绍联网刷新。

## 在客户端中使用 Skills

已安装的原生执行器通过当前宿主文档列出的 Pure Tokens 连接记录完成固定 API 请求，不需要粘贴 Key，也不需要 Node、Python、Go 或 Desktop。只问用法时不会检查连接或访问网络。

常用示例：

- `生成一张日落时分的山间湖泊图片。`
- `用 seedream-5.0-pro 生成同一主题的 3 张图片变体。`
- `生成一段 5 秒、电影感的纸船漂过河面的短视频。`
- `用当前附件作为首帧生成视频。`
- `列出支持首帧、720p 的视频模型。`
- `只检查这些生图参数，不生成。`
- `继续这个任务记录，取出尚未交付的图片。`
- `把这段文字朗读为 MP3 配音。`
- `把这份录音转成文字，不做摘要。`
- `生成下雨和脚步声的音效。`
- `生成一段舒缓的钢琴纯音乐。`
- `用这段歌词生成歌曲，歌词保持原样。`
- `查询当前可见的音频模型。`
- `查询当前 Pure Tokens 余额。`
- `用 Jev 将这条工单分到销售、技术、账务或其他。`
- `用 Jev 判断这段文本是否紧急，并按我给的三个档位评分。`
- `查询当前连接可见的 Jev 评估模型。`
- `用 qwen3.7-text-embedding 为这两条明确文本生成向量，保存到我指定的新绝对路径 embeddings.jsonl。`
- `用 qwen3.7-text-rerank 按这个查询重排以下候选，保留原编号，保存到我指定的新绝对路径 rerank.json。`
- `查询当前连接可见的向量模型。`／`查询当前连接可见的重排模型。`
- `检查是否有 Skill 更新。`／`更新 Pure Tokens Skills。`
- `诊断当前宿主的 Skill 安装和连接。`

## 音频

`puretokens-audio` 支持文字配音、录音转写和声音场景。配音最多1000字，
转写为8MiB内的 MP3/WAV/OGG，声音描述最多500字；不静默拆分或转换。
配音和音效直接返回 MP3/WAV，转写返回文本，单次同步请求最多90秒。
“生成一段纯音乐”或“按这些歌词生成歌曲” → `puretokens-audio` 的音乐路径，
使用 `stepaudio-3-music-preview` 异步提交、原任务续接和 MP3/WAV 文件交付；
明确任务记录不保存描述或歌词。需配套网关音乐 API Key 接口已部署。
音色克隆、音频翻译、实时麦克风对话尚未接入。
生成文件需要实际附加到对话才算交付；交付失败校验并重新附加原文件。
同步配音／转写／声音生成没有任务查询恢复；已有音频文件可以校验后重新交付。
异步音乐使用原任务记录续接，不能混用同步音频命令。

## 文本向量与重排

`puretokens-embedding` 将明确提供的1–64条非空文本生成向量，写入用户明确的
绝对新 `.jsonl` 文件。审核型号为 `qwen3.7-text-embedding` 和
`qwen3.7-text-embedding-flash`。每行保留零基原编号、维度和向量；
聊天只显示条数、实际维度及文件路径，不铺满向量、不自动建库或扫描目录。

`puretokens-rerank` 使用 `qwen3.7-text-rerank`，对一个非空查询和1–64条
候选文本排序，保存明确的绝对新 `.json`。top_n 可省略，默认返回全部。
结果保留从1开始的排名、从0开始的原始候选编号和原始有限相关分；
可展示与文件相同的排序摘要。分值不是概率、正确率或跨请求可比分数。

这两个入口新增于0.19.5候选，是否已正式分发以安装版本为准。同步单次最多90秒，
请求最多1 MiB、响应最多2 MiB，单条文本最多32768个 Unicode 字符，
重排查询最多8192字。先校验请求和新路径，再取凭据联网；不覆盖已有文件，
不自动拆批、隐式读文件／抓取 URL、创建数据库或通过聊天接口替代。
没有 task_id、轮询、同步结果找回或自动重试；成功必须确认
`output_verified=true`。接受后文件保存失败仍可能计费，不能自动重发。
只解释概念／用法或本地调整已有分数的展示顺序时不发付费请求。

Switch 负责让用户选择所需分组并应用客户端聊天连接，Skills 再复用当前宿主
支持的连接执行专用请求。专用模型需要 API 权限，不需进入聊天列表；
保留现有分组，按明确线上分组指引补选，不猜分组名称或代改连接。
只有用户明确查询当前可见模型才用相应 kind 的一次目录查询，
目录可见、连接配置成功或 init 成功都不保证专用接口、价格、计费或真实宿主已验收。

## 多步骤需求

可以明确要求“先生成图片，再以这张图片作首帧生成视频”，或“生成视频和独立旁白／音乐素材”。
每步先交付产物，再进入依赖它的下一步；中断后保留原任务，不重做已完成步骤。
后续模型必须支持所需本地附件传输，不能丢弃素材或偷偷换成文字。
当前没有视频音频合成、自动剪辑、混音或精确音乐时长能力，独立素材不等于已合成成片。
需要这类组合时才读媒体 Skill 的 `references/workflows.md`，单次生成不增加计划或调用。

## 把需求说具体

Jev 是文本／结构化文本的评估模型，支持 choice 分类、score 有序评分和
noul 是否判断。评估 Skill 复用当前连接，同一文本的独立问题合并请求，
同步返回数值结果；没有媒体任务轮询。置信度不等于正确率，不会据此自动
执行退款等操作。只问用法不计费调用；超时后不自动重发或推断未扣费。
首版不直接评估图片／音频／视频。默认 `jev-latest`，可指定已审查的
`jev-1.13.0` 或 `jev-preview`；目录可见不代表原生接口已完成实机验收。

| 场景 | 可以直接说 |
| --- | --- |
| 商品图 | `用附件里的杯子做一张商品主图，保留杯形和标志，背景换成白色，只有一张。` |
| 带文字的海报 | `生成一张咖啡店海报，画面上只出现“周末特调”，保留这四个字，不添加其他文案。` |
| 局部修改 | `只把这张照片的背景换成花园，人物、衣服和构图保持不变。` |
| 首帧视频 | `以附件为首帧做 5 秒视频，保留主体外观，镜头缓慢推进，不增加新角色。` |
| 只检查、不生成 | `只检查所选模型是否支持这些参数和附件，不提交生成任务。` |
| 续接原任务 | `继续这个任务记录，只取尚未交付的结果，不重新生成。` |

这些是表达意图的例子，不是新增 API 字段或效果保证。指定文字、主体、修改范围和附件用途会保留在本次请求中；不擅自改写为别的设计、增加付费任务或承诺逐像素不变。若所选模型不支持必需能力，说明限制并等待用户决定，不默默省略参考图、时长、声音要求或换模型。

仅看图、OCR、分析视频／截图错误或只写提示词，不会因此创建生成任务；询问模型能力只查目录，续接已有任务只处理原结果。两张图片不自动表示首尾帧，参考人物外观也不自动表示首帧。明确要求原样使用的提示词会逐字保留；其中“8K”等描述不自动变成 API 参数，实际输出规格仍须模型支持。

普通生成只读选中 profile，选模型或解析别名才读索引，不先查余额、目录或 init。实时目录仅用于明确查询、所需字段／操作缺口或拒绝诊断；未声明的可选参数不会提交。物理尺寸只能用作比例指导，不能直接作为 API 像素尺寸。

任务接受后先返回 ID；正常等待窗口结束仍为生成中，前台最多自动续等一个窗口，之后明确继续同一个任务，不能重置预算或自动重提。视频、多图和跨会话任务默认使用明确的工作区任务记录。可选任务记录留在用户／工作区明确位置，保存原任务、已验证参数和交付进度（含下载文件摘要），不存 prompt、凭据、参考 URL 或媒体字节。实际交付附件后才记录已交付；下载成功不等于宿主交付成功。

任务需服务端对账时停止自动等待；用户明确续接该记录时只查询同一任务一次，确认恢复后再继续。更新时若发现 Skill 目录里有个人文件或修改会停止覆盖并保留文件；先处理明确的目录冲突，不删除文件或重建安装记录来强行升级。

本地附件只随声明的 multipart 请求发送，不额外上传、不转存或改成纯文本。图片、视频、配音、音效和音乐都须实际附加原生文件才算交付；转写与评估须展示校验后的文本结果。init 成功不保证模型权限、余额、媒体创建或宿主交付；doctor 也不会把未验证的校验／交付写成成功。余额复用现有 API Key 查询：不限额 Key 显示账户钱包余额，限额 Key 显示该 Key 的剩余额度，单位 USD，不含订阅额度。精确报价、服务端幂等和无 ID 任务查找尚未提供。

文件名相同不证明是原任务产物。仅当任务记录中的下载摘要匹配时才能复用；旧记录没有摘要或文件被改写时，保留原文件并在另一个输出目录取回同一任务，不创建替代任务。ZCode 只有在宿主上下文明确选择 Pure Tokens，或用户明确指定使用它时进入媒体 Skill；连接存在本身不能证明当前会话选择。

官网入口按需求提供：独立 API 明确返回额度／余额不足时引导钱包充值；用户主动问消费明细且无法确认时引导使用记录；问钱包、Key 或套餐额度范围差异时解释范围并引导钱包信息。仅入口／范围说明不调用执行器。对话模型本身无法返回时由宿主处理，Skill 不承诺能提示；不新增 Key 管理或渠道状态跳转，不浏览器代查。

## 遇到问题时

安装完成、连接验证、任务被接受、文件下载和宿主附件交付是不同阶段。能聊天不代表 Skill 能确认当前连接，init 未验证不代表要重装；生成中不等于失败，下载成功也不代表附件已出现在对话里。

需要联系支持时，可以说：`提取刚才失败回执的安全支持摘要，不额外发请求。` 仅使用已有 `support` 块，它不含 Key、配置、提示词、媒体或本地路径；有网关请求 ID 时可用于定位该次 HTTP 请求，不保证找回无 ID 任务或判断扣费。摘要含任务／请求关联标识，只分享给私密支持，不公开整份回执或日志。旧版本没有摘要时不重跑生成来补齐。

提交响应无法读取、缺少约定位置的任务编号、编号格式不兼容是三种不同问题，都不能据此断言服务端没有生成。排障以出错客户端实际执行器版本为准，不用另一台电脑或仓库版本代替；用户要求检查时可用该执行器的 `--version`，无需重新生成。更新不会找回旧版丢弃的任务编号，已知原编号时继续查询／下载原任务。
