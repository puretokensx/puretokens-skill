# 配音、音效与音乐场景指南

只在用户要求组织描述或必要意图不清时读取。用户只写／润色配音稿、歌词或提示词时只返回文字。
已指定的正文、歌词、标点和换行逐字保留，不翻译、不添加台词／控制标签，不为了风格改写正文。

## 先区分产物

| 用户要什么 | 路径 | 需要明确的内容 |
| --- | --- | --- |
| 把这段话读出来 | 同步 speech | 原文；预设音色，未指定可用已审核默认值 |
| 把录音转成文字 | 同步 transcribe | 当前附件的实际本地字节；不摘要、不翻译 |
| 雨声、脚步、开门等环境声音 | 同步 generate | 声源、场景、前后变化 |
| 钢琴、吉他等无歌词背景音乐 | 默认 StepFun 异步 music，instrumental=true | 用户表达的风格／乐器／情绪 |
| 将歌词唱成歌曲 | 默认 StepFun 异步 music，instrumental=false | 音乐描述与原样歌词分别填写 |

“配音”不等于生成歌曲，“写歌词”不等于生成歌曲；“背景声”若可能同时指环境声或音乐，
只澄清这一项会改变操作的歧义。已有明确答案不重问，缺少可选细节不阻止生成。

## 配音

保持 input 原文，将用户明确的预设音色和语速映射到所选 profile 声明的字段。
只有 profile 支持 instruction 时才把风格要求放入该字段。不要把风格指令插入朗读正文，
也不要为不支持 instruction 的模型悄悄丢弃必需风格要求或换模型。

| 场景 | 可协助表达的风格（不是新增参数） |
| --- | --- |
| 教程旁白 | 清晰、平稳，在用户已有标点处自然停顿 |
| 商品介绍 | 自然、有活力；保留商品名称和原文 |
| 故事朗读 | 温和、富有情感；不擅自增写角色对白 |

音色只能来自当前 profile 的审核预设；不根据人物姓名或参考录音承诺克隆。
“慢一点”如不能明确映射为用户可接受的数值，说明支持的范围；不擅自更改内容。
超长原文不截断、不自动切成多个付费请求。

## 音效／声音场景

按“声音来源 → 场景 → 变化”整理用户已经表达的要素。
例如“室内听见窗外下雨，随后有脚步从远处走近”。描述中的节奏、空间感是生成意图，
不保证时间精确；没有 profile 字段时不添加 duration、循环、轨道或音量包络参数。
用户要配乐而不是环境声时进入音乐路径，不用声音生成冒充音乐模型。

## 默认 StepFun 纯音乐／歌曲

音乐描述可表达用途、风格、乐器与情绪，如“适合安静阅读的钢琴纯音乐，温暖、舒缓”。
只使用用户已有信息；用户要求原样提示词时不追加模板。

- 纯音乐：instrumental=true；不附非空 lyrics。
- 歌曲：instrumental=false；指定歌词放 lyrics，保留大小写、标点和换行。
- 用户没有给歌词且明确允许模型自由创作时可以省略，不承诺具体歌词内容。
- 仅当是否有人声会影响操作且上下文不明确时澄清；必需的参考音频、翻唱、克隆、精确时长
  当前不支持，先说明限制，不能忽略后提交。

caption/prompt、lyrics 是文本；BPM、乐器等词可作为描述，但不是新的请求字段或精确效果保证。
模型参数、字符限制和格式以所选 profile 及 music-usage.md 为准。
音频、视频分别生成不会自动混音、对齐时长或合成为一个成片。

指定 ElevenLabs 时按 [专用指南](elevenlabs-usage.md)：音乐用同步 music_sync，歌词放 instruction；变声须原录音和明确有权使用的音色 ID，不按克隆处理。
