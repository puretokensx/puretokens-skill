# 特殊图片格式

仅用户要求 GIF／动图或 SVG 时，和所选 profile 同轮读取对应段落；普通图片不读取本文件。

## GIF

GIF 是图片输出格式，不改走视频或追加转换任务。`gpt-image-2.6` 的 GIF 输出仅支持生成，不支持编辑；`gpt-image-2.6-flare`／`gpt-image-2.6-sunburst` 允许生成和编辑输出 GIF，但仅 1K。以 profile 的操作和尺寸约束为准，不把能力推广到 2.5 或其他模型；模型未指定且默认不满足格式时，先选兼容候选并确认，不先提交错误格式。执行器收到不符格式会返回 `media_output_format_mismatch`：保留原任务，不自动重生、不改后缀或转码。GIF 容器有效不保证动画帧数或创作效果，未验证不得声称已播放。

## SVG

显式 SVG 使用精确 GPT 2.6 系列 profile 的 `output_format=svg` 并保留其操作／尺寸限制。执行器只接受完整、最大 8 MiB 的安全静态 SVG；含脚本、外部资源或不支持结构时停止同任务取回，不修改文件、不转换、不重生。交付原始 `.svg` 附件，只有当前宿主明确支持时才使用安全预览；不能用助手手写 SVG 冒充 API 结果。
