# 有限多步骤媒体流程

仅在用户明确要求组合产物时读取；单次生成不用此流程。所有步骤继续使用同一已绑定 host、
原生执行器、各操作 profile 与停止条件；不是失败后的备用传输。

## 开始前

1. 从已有要求列出必要步骤、依赖和预计生成请求次数。用户已明确范围不重复索要授权；
   需要增加收费步骤、换模型或放宽必需条件时才确认这些变化。不猜价格或服务端耗时。
2. 只读将要使用的精确 profile，确认后续必需能力与附件传输；不为这个计划查询余额、目录、
   init 或 doctor。已知后续能力缺失时，在前面的付费生成之前报告限制。
3. 多阶段的异步任务使用各自唯一的明确工作区任务记录。需要跨会话继续时，在用户可见的
   项目记录中列出步骤编号、记录路径、依赖和“未尝试／已提交／待交付／已交付／停止”。
   不保存 prompt、歌词、凭据、参考 URL 或媒体字节，不把它当自动队列或幂等凭证。
   新会话缺少未执行步骤的原文时请用户补充，不从已生成媒体猜回原文。

## 图片 → 首帧视频

前提：用户明确授权两个产物，并要求使用生成的图片作视频首帧。该明确指定才使此产物成为
后续请求的用户输入；不能自动挑选历史文件。

1. 图片 submit 一次，先回执，按原记录等待、下载并实际附加；多图时只使用用户明确选择的索引。
2. 首帧使用刚校验过、未改写的本地原文件；跨会话先用图片原记录 resume 确认任务状态。
   已交付记录 done 不会重新校验该文件：另核对记录中对应索引的原路径、字节数和 SHA-256，
   不能只看同名路径。无法核实则停止，不改记录、不重新生成。
3. 视频 profile 必须声明接受本地图片的首帧 multipart operation。按其字段传同一文件；
   不另上传、不转存、不凭空生成 URL、不将图片描述成文字替代，也不通过供应商 URL 绕过传输。
   文件格式、大小或当前宿主权限不满足时停止，不自动转码或重生成图片。
4. 为视频创建新的任务记录，只 submit 一次，然后先回执并按视频契约完成交付。
   已通过本步原始字节传输才可说“使用了这张首帧”，不保证像素或运动效果完全一致。

图片阶段失败或 pending 耗尽窗口，整条依赖链停止。视频已经提交后只能继续视频原任务，
不能重做图片或再提交视频。仅当视频明确 not_submitted 且用户解决输入问题后才执行该未提交步骤。

## 视频 ＋ 独立旁白／音乐

仅交付独立素材；没有合成成片、剪辑、混音、响度处理或时长对齐能力。
用户必须得到单个带配音成片时，先说明缺口，未接受独立素材前不提交部分收费任务。

“给文字配音再配背景音乐”等音频组合也适用：当前只能生成独立配音和音乐，不能混成一条音轨。
用户没说是否接受独立文件时，先说明并确认这一个产物选择，再进行收费请求；已经明确要两份
独立素材就按已有授权执行，不重复问。单独写配音稿或歌词不提交音频任务。

- 旁白读给定原文：speech，一次同步请求；下载后实际附加，交付失败用原 artifact 的 audio-verify。
- 背景纯音乐或歌曲：默认 StepFun music 用独立异步记录；先回执，按原任务下载交付。明确指定 music_v2_5 时用同步 audio/music_sync，无远程任务恢复，按原 artifact 交付。
- 视频按其 profile 独立生成交付。用户指定先后顺序时遵守；否则按已说明的有限顺序串行。
- 每步交付后才进入下一步；某步失败、未知、对账或窗口用尽时停止整条自动流程。
  用户明确继续时只处理尚未尝试项或续接已知原任务，不重新生成已交付素材。

多个片段／分镜同样逐项记录并交付。文字中的镜头安排不是新增 API 参数，
不把超长视频请求擅自拆成多个收费片段；独立片段也不等于已经拼接。

## 恢复位置

| 本步状态 | 下一次怎么做 |
| --- | --- |
| 尚未尝试，已有范围授权仍明确 | 校验该步输入后执行一次 |
| 有原 task_id 或异步记录 | 仅 status／resume／content；依原回执，不再次 submit |
| 已下载但未附加 | 异步 resume 或同步 audio-verify 校验原文件后附加 |
| 已交付 | 保留产物，进入尚未尝试的下一步；不重复下载和生成 |
| 无编号的未知提交／同步未知 | 停止；无结果找回和自动重发保证 |
| 尚未交付的异步文件变化、不可用或跨电脑路径无效 | 不认同名文件；依原记录在新输出目录取回尚未交付的同一索引 |
| 用户明确要求再次发送已交付的异步文件 | 原记录 redeliver 指定同一索引；先核验本地，缺失才取原结果；变化／冲突用另一个输出目录，不覆盖原文件 |
| 同步音频文件丢失／变化 | 停止；没有任务结果找回接口，不改摘要、不自动重新生成 |

对账优先于表中的普通状态；单个记录的 delivered 只表示该产物的宿主交付，
不能表示整条工作流已完成。最终列出实际交付的文件与尚未完成的步骤，不宣称未执行的合成。
